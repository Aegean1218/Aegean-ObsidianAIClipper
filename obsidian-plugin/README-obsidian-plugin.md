# Obsidian 插件使用说明

Obsidian 插件 `Aegean剪藏助手` 负责接收浏览器插件发送的内容，并在当前 Obsidian 笔记库中保存、分析和归档。

## 安装

1. 打开你的 Obsidian 笔记库文件夹。
2. 进入 `.obsidian/plugins/`。
3. 如果没有 `plugins` 文件夹，就手动新建一个。
4. 把下面这个文件夹复制进去：

```text
obsidian-plugin/bookmark-ai-assistant
```

5. 打开 Obsidian。
6. 进入 `设置 → 第三方插件`。
7. 启用第三方插件。
8. 启用 `Aegean剪藏助手`。

## 首次启用

首次启用后，插件会自动创建：

```text
00_收件箱/
└── 使用说明/
    ├── 00_首次使用检查清单.md
    ├── 01_浏览器插件怎么用.md
    └── 02_Obsidian插件怎么用.md
```

这些文件用于帮助新用户在自己的 Obsidian 笔记库里完成配置和上手。

## 默认目录

- `00_收件箱/`：浏览器插件新收藏先进入这里。
- `01_网站/`：网站类收藏整理后进入这里。
- `02_文章/`：文章、公众号、长文整理后进入这里。
- `03_Git/`：GitHub 或 GitLab 项目整理后进入这里。
- `90_系统资料/附件/`：截图、公众号图片、GitHub README 图片等附件。

## 整理方式

- `分析当前收藏并归档`：只整理当前打开的收藏笔记。
- `批量分析收件箱收藏`：整理收件箱里的收藏笔记。

批量整理会跳过：

```text
00_收件箱/使用说明/
```

所以首次使用说明不会被移动。

## AI 配置

不配置 API Key 也可以：

- 收藏网页正文
- 收藏公众号文章
- 收藏 GitHub 项目
- 收藏截图
- 按基础规则归档

填写 API 地址、API Key 和模型名称后，可以获得更完整的摘要、分类、标签和文件名建议。

## 目录初始化

插件设置里有两种目录模板：

- `中文默认结构`：使用 `00_收件箱 / 01_网站 / 02_文章 / 03_Git / 20_知识专题 / 30_可复用资产`
- `极简 Inbox 模式`：收藏全部先进入 `Inbox`

也可以手动修改每一个保存目录。

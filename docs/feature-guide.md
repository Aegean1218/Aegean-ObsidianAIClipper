# Aegean剪藏助手功能说明书

版本：v0.2.2

## 一句话介绍

Aegean剪藏助手是一套面向 Obsidian 用户的本地剪藏工具，可以把网页正文、公众号文章、GitHub 项目和页面截图一键保存到 Obsidian，并按网站、文章、Git 等来源类型整理。

## 组成

- Obsidian 插件：`Aegean剪藏助手`
- Chrome 浏览器插件：`Obsidian 收藏助手`

浏览器插件负责提取内容，Obsidian 插件负责接收、保存和整理。

## 核心功能

### 网页正文收藏

保存页面标题、链接、描述、正文和收藏时间。

### 公众号文章收藏

保存公众号标题、链接、正文、图片和富文本层级。

### GitHub 项目收藏

保存仓库信息、README 内容、README 图片和原始 HTML 备份。

### 页面截图收藏

保存当前网页可见区域截图，适合工具站、后台页面和视觉参考。

### 收件箱初始化

首次启用 Obsidian 插件后，会自动创建：

```text
00_收件箱/
└── 使用说明/
    ├── 00_首次使用检查清单.md
    ├── 01_浏览器插件怎么用.md
    └── 02_Obsidian插件怎么用.md
```

新用户按说明文件操作即可完成安装和测试。

### 一键整理

插件提供两个整理入口：

- `分析当前收藏并归档`
- `批量分析收件箱收藏`

整理后的默认目录：

- 网站类：`01_网站/`
- 文章类：`02_文章/`
- Git 类：`03_Git/`

批量整理会跳过 `00_收件箱/使用说明/`。

### 无 API Key 也能使用

不配置 API Key 时，仍然可以收藏、保存附件和按基础规则归档。

配置 API Key 后，可以获得自动摘要、分类、标签和文件名建议。

## 适合人群

- 用 Obsidian 做资料库的人
- 经常收藏网页、公众号、GitHub 项目的人
- 做产品、运营、设计、研发、内容创作的人
- 不想让浏览器书签和微信收藏继续堆积的人

## 不适合的场景

- 不使用 Obsidian
- 只想临时稍后读，不打算沉淀资料
- 希望插件自动打开 Obsidian
- 希望所有内容自动同步到云端平台

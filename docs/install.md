# Aegean剪藏助手安装说明

这个工具由两部分组成，必须两边都安装：

- Obsidian 插件：负责接收网页内容，并写入当前笔记库。
- 浏览器插件：负责从网页、公众号、GitHub 或截图中提取内容。

## 第一步：安装 Obsidian 插件

1. 打开你的 Obsidian 笔记库文件夹。
2. 进入 `.obsidian/plugins/`。
3. 如果没有 `plugins` 文件夹，就手动新建一个。
4. 把这个文件夹复制进去：

```text
obsidian-plugin/bookmark-ai-assistant
```

5. 打开 Obsidian。
6. 进入 `设置 → 第三方插件`。
7. 启用第三方插件。
8. 启用 `Aegean剪藏助手`。

启用后，插件会在当前笔记库中创建 `00_收件箱/使用说明/`，里面有首次使用检查清单和功能说明。

## 第二步：安装浏览器插件

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 打开右上角的 `开发者模式`。
3. 点击 `加载已解压的扩展程序`。
4. 选择这个文件夹：

```text
browser-extension/browser-capture-extension
```

5. 固定 `Obsidian 收藏助手` 到工具栏。

## 第三步：确认连接

1. 先打开 Obsidian。
2. 确认 `Aegean剪藏助手` 已启用。
3. 打开浏览器插件面板。
4. 点击 `重新检测`。
5. 确认面板显示 `Obsidian 已连接`。

## 第四步：测试收藏

1. 打开一篇普通网页。
2. 点击浏览器插件里的 `正文收藏`。
3. 回到 Obsidian。
4. 确认 `00_收件箱/` 中出现新收藏。

## 常见问题

### 为什么提示先打开 Obsidian？

浏览器插件不会自动打开 Obsidian。请先打开 Obsidian，并确认 `Aegean剪藏助手` 已启用。

### 一键整理后文件去了哪里？

新收藏先进入 `00_收件箱/`。整理后会移动到：

- `01_网站/`
- `02_文章/`
- `03_Git/`

`00_收件箱/使用说明/` 不会被批量整理移动。

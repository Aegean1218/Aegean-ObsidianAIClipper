# 浏览器插件使用说明

浏览器插件负责从当前网页提取内容，并发送给已经打开的 Obsidian。

## 安装

1. 打开 Chrome。
2. 进入 `chrome://extensions/`。
3. 打开右上角 `开发者模式`。
4. 点击 `加载已解压的扩展程序`。
5. 选择这个文件夹：

```text
browser-extension/browser-capture-extension
```

6. 把 `Obsidian 收藏助手` 固定到浏览器工具栏。

## 使用前确认

1. 先打开 Obsidian。
2. 确认 Obsidian 中已经启用 `Aegean剪藏助手`。
3. 打开浏览器插件面板。
4. 点击 `重新检测`。
5. 看到 `Obsidian 已连接` 后再开始收藏。

## 功能入口

- `正文收藏`：保存网页标题、链接、页面描述和正文，适合教程、博客、长文资料。
- `截图收藏`：保存当前可见区域截图，适合工具站、后台页面、设计参考。
- `公众号文章`：保存公众号文章正文、图片和富文本层级。
- `GitHub 项目`：保存仓库信息、README 内容和 README 图片。

## 保存到哪里

浏览器插件不会直接写入文件，它会把内容发送给 Obsidian 插件。Obsidian 插件默认会把新收藏写入：

```text
00_收件箱/
```

之后可以在 Obsidian 中单个整理或批量整理。

## 如果没有连接

这个插件不会自动打开 Obsidian。看到未连接提示时，按顺序检查：

1. Obsidian 是否已经打开。
2. `Aegean剪藏助手` 是否已经启用。
3. 浏览器插件高级设置里的地址是否为默认地址。
4. 在 Obsidian 里关闭再开启一次 `Aegean剪藏助手`。
